## O que são?
Sets são uma coleção não ordenada de elementos que não podem se repetir.
Pode ser usado para checar se existe elementos duplicados em uma coleção.

## Como usar?
Para criar podemos usar {} ou .set()
Para adicionar elementos podemos usar .add(elemento)
Para remover usamos o .remove(elemento)
Para checar se um elemento existe dentro de um set podemos usar in, ex:
 `if num in list`
## Complexidade:
Busca:      O(n)
Inserção:  O(n)
Deleção:  O(n)
