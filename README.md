# Estudos

Este repositório é onde guardo minhas anotações de programação enquanto estudo e aprendo coisas novas.

A ideia é ter um lugar para consultar conceitos, registrar aprendizados e organizar o que considero importante ao longo do tempo.

Como estou sempre estudando, o conteúdo pode mudar, ser reorganizado ou atualizado conforme necessário.

Isso funciona como uma Vault do Obsidian. Se quiser visualizar o conteúdo com uma interface mais limpa e a formatação correta, essa é a melhor forma.
